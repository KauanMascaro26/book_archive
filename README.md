# Book Archive

Sistema para gerenciamento de acervo e empréstimo de livros.

## Tecnologias

### Mobile

* Flutter
* Dart

### Backend

* Python
* FastAPI

### Database

* PostgreSQL

## Architecture

```text
Flutter Mobile App
        ↓
    REST API
        ↓
   FastAPI
        ↓
   PostgreSQL
```
